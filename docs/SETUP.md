# Setup

## Required

- Godot 4.6.x stable
- Git
- Git LFS

## Recommended

- Aseprite or LibreSprite
- Audacity
- jsfxr or ChipTone

## First Run

```powershell
git lfs install
.\tools\validate_project.ps1
```

Then open this folder in Godot and run `scenes/main/Main.tscn`.
