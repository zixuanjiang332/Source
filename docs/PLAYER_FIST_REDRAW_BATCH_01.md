# Player Fist Redraw Batch 01

本批次只做 9 帧，是当前最值得先强化的一组正式拳头帧。目标是用最少改动，把“拳头开局”的力量层级先立起来。

批次范围：

- `punch_1`: `01 / 03 / 05`
- `punch_2`: `01 / 03 / 05`
- `punch_3`: `02 / 05 / 07`

## 1. punch_1_01

当前作用：

- 第一拳预备
- 负责告诉玩家“这一拳是快拳开手”

保留：

- 前压方向
- 小幅度前手先行的节奏

必须加强：

- 后脚压地感
- 前肩内收
- 拳架主次

不要再出现：

- 普通站姿直接出拳
- 身体没压低就开打

## 2. punch_1_03

当前作用：

- 第一拳主命中
- 负责建立“短、准、直”的第一印象

保留：

- 直线出拳方向
- 前手开路的节奏

必须加强：

- 肩带拳
- 命中轮廓更干净
- 腰胯轻微送拳

不要再出现：

- 手比身体快很多，像胳膊自己飞出去
- 命中帧发飘

## 3. punch_1_05

当前作用：

- 第一拳回收
- 负责把动作顺到第二拳

保留：

- 回收节奏

必须加强：

- 收势时的攻击性
- 后手回护
- 重心还留在前方一点

不要再出现：

- 像动作结束收工
- 回到中立站姿太快

## 4. punch_2_01

当前作用：

- 第二拳蓄力
- 负责和第一拳拉开重量差

保留：

- 连段连续性

必须加强：

- 后肩后拉
- 骨盆反拧
- 身体像在拧弹簧

不要再出现：

- 只是第一拳姿势换个手
- 上下身没明显蓄力关系

## 5. punch_2_03

当前作用：

- 第二拳主命中
- 负责表现“后手更重”

保留：

- 命中方向

必须加强：

- 后手整个人送出去的感觉
- 髋肩联动
- 比第一拳更明显的穿透

不要再出现：

- 还是像刺拳
- 只是镜像第一拳

## 6. punch_2_05

当前作用：

- 第二拳制动
- 负责衔接第三拳重击

保留：

- 连段不断开的节奏

必须加强：

- 惯性被吃住
- 身体继续向前施压
- 给第三拳留更低的重心

不要再出现：

- 命中后过早回正
- 回收比第一拳还轻

## 7. punch_3_02

当前作用：

- 第三拳深读招
- 负责给整套连段立高潮

保留：

- 大体前压方向

必须加强：

- 下沉
- 蓄力更明显
- 受力腿更清楚

不要再出现：

- 读招不够重
- 看不出这是终结拳前摇

## 8. punch_3_05

当前作用：

- 第三拳主命中
- 这是整套里最该重做好的帧

保留：

- 前送路线

必须加强：

- 最大轮廓
- 最大重量
- 最大压迫感

不要再出现：

- 还像普通第二拳延长版
- 命中后没有“砸实”感

## 9. punch_3_07

当前作用：

- 第三拳重收势
- 负责让终结拳有半拍压地感

保留：

- 终结后慢半拍回来的节奏

必须加强：

- 脚底稳
- 身体吃住惯性
- 收势还保留威胁感

不要再出现：

- 瞬间站直
- 收完像回待机

## 批次验收标准

这 9 帧替换完后，至少满足：

1. `punch_1 < punch_2 < punch_3` 的重量层级明显成立
2. 第一拳像快拳，第二拳像后手重拳，第三拳像终结拳
3. 每段都有“预备 -> 命中 -> 收势”的清楚关系
4. 单独抽帧看，也能读出这是拳头动作，不是刀动作

## 建议执行顺序

1. 先改 `punch_3_02 / 05 / 07`
2. 再改 `punch_1_01 / 03 / 05`
3. 最后改 `punch_2_01 / 03 / 05`

这样能最快把整套拳头手感从“可用”推到“有说服力”。
