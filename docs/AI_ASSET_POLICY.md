# AI 辅助素材使用规则

本项目允许 AI 生成图、动作帧和 spritesheet 直接作为 `final` 游戏素材接入。负责人只需要先明确设计意图、规格和禁用元素；如果后续要改成必须人工重绘或降低某批素材状态，再单独提出决策和 PR。

## 1. 允许

- 生成角色轮廓灵感。
- 生成道具图标参考。
- 生成特效形状参考。
- 生成场景材料参考。
- 生成临时占位图帮助程序接入。
- 根据人工草图做风格探索。
- 生成可直接进入 `assets/` 的最终单帧、动作帧或 spritesheet。

## 2. 不允许

- 在没有负责人设计说明和验收的情况下批量提交素材。
- 让 AI 单独决定主角最终形象。
- 让 AI 单独决定核心美术风格。
- 使用带水印、版权角色、明显商用 IP 特征的图。
- 生成与死亡细胞、小骨等作品过于接近的具体角色或敌人。

## 2.1 Final 接入条件

AI 生成图或动作帧可以作为 `final` 进入 `assets/`，适用于角色、敌人、Boss、VFX、UI、图标、道具、背景 tiles/props 等所有素材类型。

进入 `final` 前必须满足：

- 保存原始 AI 源图或逐帧文件。
- 运行时 PNG / OGG / WAV 等文件尺寸、帧数、命名和格式符合对应交付规范。
- 在 `ASSET_MANIFEST.csv` 标注 `final`，并在备注中写明 `AI generated` 或 `AI generated frames`。
- Godot 场景无 Missing Resource；战斗相关素材必须通过可读性检查。

## 3. 标记规则

AI 素材放入临时资料或进入项目时必须标记：

```text
用途: final / reference / placeholder / rejected / paintover_base
生成日期:
负责人:
是否进入正式素材: yes / no
```

正式提交到 `assets/` 的 AI 素材不要求先人工重绘，但必须经过负责人验收，并在素材清单中标注状态和来源。

## 4. 风格控制

每次 AI 生成前由人先确定：

- 对象功能。
- 轮廓关键词。
- 主色和辅助色。
- 动作状态。
- 画布尺寸。
- 禁止出现的元素。

AI 输出可以作为最终成品。后续如果负责人要求重绘、替换或降级为参考图，另开任务处理。
