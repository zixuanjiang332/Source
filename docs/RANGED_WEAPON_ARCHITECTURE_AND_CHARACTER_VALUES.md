# 远程武器架构、射击方式与人物基础数值设计

> 版本：灰盒骨架完善版  
> 适用项目：Neon Machine Demo  
> 目标：统一远程武器的数据结构、射击方式、攻速换算规则，并用中文沉淀当前所有人物基础数值。

---

## 一、设计目标

远程武器需要服务 2D 像素动作的核心手感：读得清、反馈快、数值可调、不会压过近战武器。当前项目已经具备 `WeaponData`、`AttackData`、`Projectile`、玩家自动连射、弹匣/换弹、HUD 弹药显示与远程武器被动基础逻辑，本文件在现有实现上补全架构边界和后续扩展规则。

### 核心原则

- **数据驱动**：伤害、射速、射程、弹速、穿透、技能和被动优先写入 `.tres`，脚本只解释数据。
- **射击与命中解耦**：玩家只负责生成射击请求；子弹、射线或特殊弹道负责命中；受击仍统一走 `Hurtbox.receive_hit()`。
- **远近手感区分**：近战强调位移、硬直、打击停顿；远程强调瞄准、弹道、节奏和弹药管理。
- **攻速口径统一**：策划表里保留“攻速评分”，运行时统一换算成每秒发射次数和射击间隔。
- **反馈走事件总线**：VFX、SFX、镜头震动继续通过 `GameEvents` 请求，不在武器或子弹里直接驱动场景表现。

## 二、现有远程武器数据流

```text
Input.attack 长按/点按
  → PlayerController._try_ranged_attack()
  → WeaponData.attack_mode 分发
      → projectile: Projectile.fire()
      → hitscan: PhysicsRayQueryParameters2D 射线检测
  → Hurtbox.receive_hit(AttackData, source, hit_position, facing)
  → receiver.apply_hit()
  → GameEvents 请求 VFX/SFX/镜头震动/HUD 更新
```

### 现有脚本职责

| 模块 | 当前职责 | 后续约束 |
| --- | --- | --- |
| `WeaponData` | 保存武器基础信息、武器类型、攻速评分、远程射程、弹速、子弹颜色、被动和技能参数 | 新增远程字段时优先放这里或独立 `RangedFireData`，不要散落在玩家脚本里 |
| `AttackData` | 保存单次命中的伤害、击退、硬直、冷却、命中停顿、VFX/SFX、回能 | 只描述“命中包”，不描述弹道形态 |
| `Projectile` | 实体子弹飞行、寿命、穿透计数、命中 Hurtbox、触发命中信号 | 不处理武器被动的最终效果，只回传命中结果 |
| `PlayerController` | 读取输入、计算瞄准方向、生成射击、处理远程武器被动、回能和技能状态 | 后续应逐步把射击模式拆到独立组件，降低玩家脚本复杂度 |
| `GameEvents` | 广播远程命中、VFX、SFX、镜头震动、提示文本 | 远程武器不能绕过事件总线直接操作 UI 或 VFX 节点 |

## 三、推荐远程武器架构

### 3.1 数据层

短期继续使用 `WeaponData`，中期可新增 `RangedFireData.gd` 作为子资源，避免 `WeaponData` 字段无限膨胀。

#### `WeaponData` 保留字段

| 字段 | 中文含义 | 用法 |
| --- | --- | --- |
| `weapon_type` | 武器类型 | 远程武器统一为 `ranged` |
| `attack_mode` | 攻击模式 | `projectile`、`hitscan`，后续可扩展 `beam`、`lobbed` |
| `base_damage_rating` | 基础伤害评分 | 用于 HUD、描述和部分被动计算 |
| `attack_speed_rating` | 攻速评分 | 统一换算为射击间隔 |
| `ammo_capacity` | 弹容量 | `0` 表示无备弹限制；大于 0 表示存在总备弹上限 |
| `ranged_range` | 有效射程 | hitscan 的射线长度；projectile 的推荐最大有效距离 |
| `ranged_pierce_count` | 穿透目标数 | 技能或强化状态可临时提高 |
| `projectile_speed` | 子弹速度 | 实体投射物每秒移动像素数 |
| `projectile_lifetime` | 子弹寿命 | 与弹速共同决定最大飞行距离 |
| `projectile_color` | 子弹颜色 | 灰盒阶段区分武器与属性 |

#### 推荐新增字段

| 字段 | 类型 | 中文含义 | 说明 |
| --- | --- | --- | --- |
| `trigger_mode` | `StringName` | 扳机模式 | 已接入：`semi_auto` 单发、`auto` 连射、`charge` 蓄力 |
| `fire_pattern` | `StringName` | 射击形态 | 已接入：`single` 单弹、`burst` 点射、`spread` 散射；预留 `beam`、`lobbed` |
| `burst_count` | `int` | 点射发数 | 如 3 连发、5 连发 |
| `burst_interval` | `float` | 点射内间隔 | 单次按键内多发子弹之间的间隔 |
| `pellet_count` | `int` | 单次弹丸数 | 霰弹或能量散射使用 |
| `spread_angle` | `float` | 散射角度 | 以角度为单位，左右均匀分布 |
| `reload_time` | `float` | 换弹时间 | 已接入；弹匣打空或按 `R` 主动换弹触发 |
| `magazine_size` | `int` | 弹匣容量 | 已接入；与 `ammo_capacity` 区分：弹匣 vs 总备弹 |
| `recoil_impulse` | `float` | 后坐力 | 影响玩家水平速度或枪口偏移 |
| `aim_slow_scale` | `float` | 射击移速倍率 | 长按射击时限制移动，强化动作感 |
| `crit_range_min` | `float` | 最佳射程起点 | 用于霰弹、狙击等距离收益设计 |
| `crit_range_max` | `float` | 最佳射程终点 | 超出范围可衰减伤害 |

### 3.2 运行层拆分建议

当前远程逻辑主要在 `PlayerController` 内。后续推荐按以下节点拆分，避免玩家脚本继续变长：

```text
PlayerController
  ├─ WeaponRuntime                 # 装备、切换、技能状态、弹药状态
  ├─ RangedFireController           # 输入节奏、攻速、射击模式分发
  ├─ MuzzleAnchor                   # 枪口位置
  └─ Hitbox/Hurtbox                 # 近战与受击仍保留原结构

Projectile.tscn                    # 普通实体弹
Beam.tscn                          # 持续光束，可后续新增
LobbedProjectile.tscn              # 抛物线/榴弹，可后续新增
```

#### 拆分后的职责边界

| 模块 | 应该做 | 不应该做 |
| --- | --- | --- |
| `WeaponRuntime` | 管理当前武器、弹药、换弹、强化弹、技能计时 | 不直接生成 VFX，不直接伤害敌人 |
| `RangedFireController` | 根据输入和攻速判断是否允许开火，计算弹丸方向和数量 | 不修改玩家生命/敌人生命 |
| `Projectile` | 飞行、碰撞、寿命、穿透、命中回调 | 不判断武器被动最终数值 |
| `AttackData` | 提供命中包 | 不保存弹道参数 |
| `Hurtbox` | 转发受击 | 不知道攻击来自近战还是远程 |

## 四、射击方式设计

### 4.1 基础射击方式

| 射击方式 | `attack_mode` / `fire_pattern` | 手感定位 | 适合武器 | 实现要点 |
| --- | --- | --- | --- | --- |
| 实体单发 | `projectile` / `single` | 有飞行时间、可躲、反馈清晰 | 手枪、能量步枪、水波弹 | 生成 1 个 `Projectile`，按鼠标方向飞行 |
| 即时射线 | `hitscan` / `single` | 立即命中，适合高科技枪械 | 激光手枪、狙击、测试武器 | 用射线收集 Hurtbox，表现上补枪线 VFX |
| 全自动连射 | `projectile` / `single` + `auto` | 持续压制，DPS 稳定 | 手枪、冲锋枪、次世代 | 长按攻击，按射击间隔循环触发 |
| 点射 | `projectile` / `burst` | 一次输入多发，节奏强 | 三连能量枪、战术步枪 | 单次开火进入 burst 子状态，内部按 `burst_interval` 发射 |
| 散射 | `projectile` / `spread` | 近距离爆发，远距离衰减 | 霰弹、扇形电弧 | 同时生成多个弹丸，方向在 `spread_angle` 内分布 |
| 穿透弹 | `projectile` / `single` | 打排队敌人，强调站位 | 澎湃技能、穿甲饰品 | 提高 `ranged_pierce_count`，命中多个不同目标 |
| 蓄力弹 | `projectile` / `charge` | 风险换爆发 | 重炮、轨道枪 | 按住积累倍率，松开消耗一次攻击 |
| 抛射弹 | `lobbed` / `single` | 越障、区域控制 | 榴弹、能量球 | 使用重力或曲线移动，落点爆炸检测范围 |
| 持续光束 | `beam` / `channel` | 持续接触伤害 | 激光、链电 | 每 tick 对射线范围内目标造成低额伤害 |

### 4.2 当前三把远程武器定位

| 武器 | 当前定位 | 推荐射击方式 | 节奏关键词 | 平衡风险 |
| --- | --- | --- | --- | --- |
| 手枪 | 初始远程、无备弹限制、低伤高频 | 实体单发 + 全自动连射 | 稳定、轻量、补刀 | 无限备弹不能有过高 DPS，否则会压过近战 |
| 次世代 | 雷属性高速武器，24 发后强化冲击波弹 | 高速实体弹 + 强化弹 | 快、聚拢、爆发窗口 | 攻速高时容易刷被动，需要用阈值、换弹窗口和伤害控制 |
| 澎湃 | 水属性高伤武器，技能期穿透 | 慢速重弹 + 技能穿透弹 | 重击、穿线、打精英 | 基础伤害高，必须控制射速、换弹窗口和命中难度 |

### 4.3 推荐操作规则

- **鼠标瞄准**：远程武器按枪口到鼠标的方向射击；若鼠标距离过近，使用角色朝向。
- **长按连射**：`trigger_mode = auto` 的武器长按 `attack` 自动开火。
- **半自动**：`trigger_mode = semi_auto` 的武器只响应 `attack` 刚按下，适合高伤武器。
- **技能键独立**：`skill` 只触发武器技能，不与普通射击抢冷却。
- **冲刺限制**：冲刺中不允许普通远程开火，避免高速位移 + 安全输出过强。
- **终结技限制**：终结技期间不允许普通远程开火，避免动画和命中状态重叠。

## 五、游戏攻速设计

### 5.1 攻速评分口径

策划表继续使用整数“攻速评分”，便于直觉配置。运行时统一换算为“射击间隔”。

```text
射速倍率 = max(0.1, attack_speed_rating / 100.0)
基础射击间隔 = 0.30 / 射速倍率
最终射击间隔 = clamp(基础射击间隔 / 攻速加成倍率, 0.08, 1.20)
每秒发射次数 = 1.0 / 最终射击间隔
```

> 当前远程实现已经使用 `0.30 / (attack_speed_rating / 100.0)`，并设置最低射击间隔 `0.08` 秒。后续如果接入饰品、Buff 或减益，应统一进入“攻速加成倍率”，不要重复改 `AttackData.cooldown` 和 `WeaponData.attack_speed_scale`。

### 5.2 推荐攻速档位

| 攻速评分 | 射击间隔 | 每秒发射次数 | 手感描述 | 推荐用途 |
| ---: | ---: | ---: | --- | --- |
| 30 | 1.00 秒 | 1.00 发/秒 | 很慢、重击 | 榴弹、狙击、蓄力炮 |
| 40 | 0.75 秒 | 1.33 发/秒 | 慢、单发有分量 | 高伤手炮、重弩 |
| 50 | 0.60 秒 | 1.67 发/秒 | 中慢 | 精准步枪、强力手枪 |
| 70 | 0.43 秒 | 2.33 发/秒 | 中速 | 标准步枪、战术点射 |
| 100 | 0.30 秒 | 3.33 发/秒 | 快速 | 初始手枪、常规自动枪 |
| 130 | 0.23 秒 | 4.33 发/秒 | 很快 | 高级能量武器、技能期武器 |
| 200 | 0.15 秒 | 6.67 发/秒 | 极快 | 次世代高速枪、短时爆发 |
| 300 | 0.10 秒 | 10.00 发/秒 | 接近上限 | 只建议用于限时 Buff 或 Boss 技能 |
| 375+ | 0.08 秒 | 12.50 发/秒 | 系统下限 | 不建议常驻，容易造成特效和判定压力 |

### 5.3 远程武器 DPS 控制

```text
理论 DPS = 单发伤害 × 每秒发射次数 × 命中率 × 目标修正
```

推荐命中率假设：

| 武器类型 | 灰盒命中率假设 | 说明 |
| --- | ---: | --- |
| 近距离自动枪 | 80% | 玩家容易贴脸输出，但风险更高 |
| 中距离手枪/步枪 | 65% | 常规移动战基准 |
| 高速小子弹 | 55% | 弹丸多但单发轻，允许部分丢失 |
| 慢速重弹 | 45% | 命中需要预判，单发伤害更高 |
| 散射武器 | 35%～90% | 取决于距离，近距离多弹丸命中 |

### 5.4 当前远程武器按攻速评分换算

| 武器 | 伤害评分 | 攻速评分 | 射击间隔 | 每秒发射次数 | 理论满命中 DPS | 设计判断 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 手枪 | 5 | 100 | 0.30 秒 | 3.33 发/秒 | 16.7 | 无限备弹的安全补刀武器，DPS 应低于主力近战 |
| 次世代 | 30 | 200 | 0.15 秒 | 6.67 发/秒 | 200.0 | 高速主力远程，靠换弹、被动阈值和技能冷却控强度 |
| 澎湃 | 150 | 130 | 0.23 秒 | 4.33 发/秒 | 650.0 | 当前理论 DPS 极高，应以换弹、命中难度、冷却或伤害公式限制 |

### 5.5 平衡建议

- **无限备弹武器**：理论满命中 DPS 建议控制在同阶段近战的 30%～50%。
- **高爆发远程武器**：允许爆发 DPS 高于近战，但需要通过弹匣、换弹、命中难度或技能窗口限制持续输出。
- **高攻速武器**：单发伤害低、击退低、命中停顿低，避免频繁卡顿。
- **高伤害武器**：攻速低、弹速慢或后摇长，确保敌人有反应空间。
- **穿透武器**：单体 DPS 不应同时过高，否则会同时成为清杂和打 Boss 最优解。
- **属性被动**：雷的控制、风的移速、水的生命/穿透、火的叠伤都应有 Boss 折减规则。

## 七、弹药与换弹设计

### 7.1 弹药口径

| 字段 | 含义 | 推荐规则 |
| --- | --- | --- |
| `ammo_capacity = 0` | 无备弹限制 | 默认规则；只通过弹匣与换弹控制输出节奏 |
| `ammo_capacity > 0` | 总弹药上限 | 只用于少数特殊武器、关卡机制或挑战模式 |
| `magazine_size` | 弹匣容量 | 已接入；控制单次连续输出长度 |
| `reload_time` | 换弹时间 | 已接入；用于区分持续 DPS 与爆发 DPS |

### 7.2 当前阶段推荐

- 当前灰盒默认使用“无限备弹 + 弹匣换弹”规则；后续只需继续补齐更细的换弹表现和音画反馈。
- 手枪、次世代和澎湃当前都没有总备弹限制，永远不会因为耗尽备弹失去普通射击能力。
- 武器节奏主要由弹匣容量、换弹时间、攻速、被动阈值与技能冷却共同控制。
- 武器技能是否耗弹药按武器单独配置；当前默认技能不消耗普通弹药，只走冷却或充能。

## 九、人物数值分层解读

### 玩家

- 玩家最大生命 100、最大能量 100，是所有战斗容错和技能循环的基准。
- 玩家移动速度 135 px/s，显著高于多数敌人，鼓励走位、拉扯和冲刺切入。
- 冲刺速度 405 px/s、持续 0.13 秒、冷却 0.38 秒，定位为短促闪避而不是长距离位移。

### 普通怪

- 普通怪生命分布为 70～200，符合“普通怪 2～4 次轻攻击击杀”的早期目标。
- 接触伤害主要在 8～35 之间，用于惩罚贴脸失误，不应一击造成过高损失。
- 速度较快的 `Conveyor Claw` 和 `Scout Drone` 应承担压迫与打断节奏的职责。

### 精英怪

- 精英怪生命分布为 600～1080，承担 6～8 次攻击或一轮技能爆发的目标。
- `Pulse Praetorian` 接触伤害 75，属于高威胁精英，需要清晰前摇和碰撞反馈。
- `Furnace Cerberus` 移速 85，是当前敌人中机动性最高的一档，应避免同时拥有过高控制抗性。

### Boss

- `Foundry Warden` 生命 1800，适合作为垂直切片阶段 Boss 或中段守门人。
- `Final Warden` 生命 4000、接触伤害 250，属于最终战数值；必须配合明显招式前摇和安全窗口。
- Boss 不应被普通聚拢、硬控、斩杀直接破坏流程；所有远程被动需要 Boss 版折减逻辑。
