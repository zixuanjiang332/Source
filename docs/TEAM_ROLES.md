# Team Roles

## Programmer A

- 玩家输入、移动、冲刺、攻击状态。
- Hitbox/Hurtbox 战斗框架。
- 玩家 HUD 数据接入。

## Programmer B

- 敌人 AI、Boss 展示战、关卡交互。
- VFX/SFX 接入。
- Windows 导出和性能检查。

## Designer

- Demo 路线节奏。
- 敌人和道具数值表。
- 每周验收清单。

## Pixel/VFX Owner

- 主角、敌人、Boss 像素动画。
- 特效帧动画和视觉规范。
- 场景瓦片、道具图标。
- 与程序确认每个动画的帧数、碰撞窗口和导出命名。
