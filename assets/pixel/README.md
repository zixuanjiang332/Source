# Pixel Export Targets

推荐导出尺寸：

- Player canvas: 96x96
- Normal enemy canvas: 96x96 or 128x128
- Boss canvas: 192x192
- Tile size: 32x32
- Item icon: 32x32 and 64x64
- VFX canvas: 64x64, 96x96, or 128x128

动画标签固定：

`idle`, `run`, `jump`, `fall`, `dash`, `atk_1`, `atk_2`, `atk_3`, `skill`, `hit`, `death`
