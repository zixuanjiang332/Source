# Yuan Fist Pass Frame-by-Frame Prompts

本文档把拳头连段与技能拆到逐帧级别。推荐用法不是一次性全量生成，而是：

1. 先生成关键帧候选。
2. 选中同一条动作语言。
3. 再用本文件补中间帧。

通用前缀建议始终附加：

```text

```
