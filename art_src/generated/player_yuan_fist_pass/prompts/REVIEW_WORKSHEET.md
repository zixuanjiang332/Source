# Yuan Fist Pass Review Worksheet

这份表用于筛图。目标不是判断“单帧好不好看”，而是判断这套动作播起来有没有力量、顺不顺、能不能接进游戏。

## 1. 审核顺序

按这个顺序看：

1. 关键帧是否成立
2. 前后动作语言是否统一
3. 中间帧是否顺
4. 是否适合接入 Godot

## 2. 关键帧先审

每个动作优先看这些帧：

| 动作 | 关键帧 |
|---|---|
| `combat_idle` | 1 / 4 / 7 |
| `combat_run` | 1 / 3 / 5 / 7 |
| `punch_1` | 2 / 4 / 6 |
| `punch_2` | 2 / 4 / 6 |
| `punch_3` | 3 / 6 / 8 |
| `punch_skill` | 2 / 4 / 7 / 9 |

如果关键帧本身不成立，不要急着补中间帧。

## 3. 五项主评分

每个动作都按 1-5 分记录：

| 项目 | 说明 |
|---|---|
| 力量感 | 是否看得出蓄力、释放、收势，命中帧是否够重 |
| 流畅度 | 相邻帧是否连续，重心与脚底是否稳定 |
| 轮廓可读性 | 抽一帧看能否读出拳头方向和躯干转向 |
| 动作区分度 | 三段拳是否各有节奏和重量差异 |
| 游戏适配度 | 是否能接进现有 96x96、侧视、Godot Runtime |

## 4. 硬性淘汰项

出现任意一条，直接判废或重做：

- 脚底大幅跳动
- 双手主次不分
- 多余手臂或重复拳头
- 像持刀斩击，不像拳头攻击
- 命中帧比预备帧还缩
- 收招直接跳回站姿，没有惯性
- 比例和现有待机体型差太多

## 5. 动作专项检查

## 5.1 combat_idle

- 看起来是否像“能立刻前压”的拳架，而不是普通站立
- 前后手是否不对称
- 呼吸和重心切换是否自然

## 5.2 combat_run

- 上身是否保持战斗感
- 头部是否乱跳
- 手臂是否像跑步比赛而不是战斗追击

## 5.3 punch_1

- 是否短促、快、准
- 是否主要由前肩送拳，不是只有前臂在戳
- 是否能自然接 `punch_2`

## 5.4 punch_2

- 是否明显比 `punch_1` 更重
- 是否看得出后手和转髋发力
- 是否不是 `punch_1` 的简单镜像

## 5.5 punch_3

- 是否是整套里最重的一段
- 是否有明确的压步或压身感
- 命中后是否保留半拍重量

## 5.6 punch_skill

- 位移感和重量感是否同时成立
- 残影是否只是辅助，而不是遮住本体
- 技能结束后是否能回到可控状态

## 7. 推荐推进方式

- 先让 `punch_1` 过审，再做 `punch_2`
- 不要三段拳同时大面积细修
- 每过一段，就进 Godot 试播一轮

这样最容易把“好看的单帧”变成“真正能打的动作”。
